# 🎬 CineTrack — Your Watchlist. Your Journey. Your Universe.

A personal entertainment management platform designed to help users organize, track, rate, and explore their favorite movies, anime, and TV series — all in one place.

## 📌 Project Overview

**CineTrack** is a responsive, browser-based watchlist management application built using HTML, CSS, and Vanilla JavaScript.

It provides a centralized space to manage entertainment collections, track episode progress, write personal reviews, organize favorites, and analyze viewing habits.

With LocalStorage integration, users can manage their entertainment library without requiring an external database or backend.

## ✨ Key Features

### 📊 1. Interactive Dashboard
- Total titles in your library.
- Completion percentage.
- Currently watching count.
- Total episodes watched.
- Estimated screen time.
- Continue Watching section.
- Recently added titles.

### 📚 2. My Library
- Centralized movie, anime, and TV series collection.
- Real-time search functionality.
- Filter by format, genre, status, and streaming platform.
- Sort by title, rating, and release year.
- Grid and list view options.

### ▶️ 3. Episode Tracking
- Track watched and remaining episodes.
- Quick +1 and -1 episode controls.
- Visual progress bars.
- Automatically mark titles as completed when all episodes are watched.
- Record last-watched episode notes.

### 🔖 4. Watchlist Management
- Plan to Watch.
- Currently Watching.
- Completed.
- Favorites.
- Dropped titles.
- Easily change titles between different watch statuses.

### ⭐ 5. Ratings & Reviews
- Personal ratings from 1.0 to 10.0.
- Write and edit personal reviews.
- Review cards for completed titles.
- Dedicated favorites collection.

### 🎥 6. Entertainment Categories
- Movies with runtime, director, and release year.
- Anime with episode tracking.
- TV Series with season and episode information.
- Streaming platform information.

### 📈 7. Statistics & Analytics
- Watch status distribution.
- Media type breakdown.
- Top genres analysis.
- Rating distribution.
- Total estimated watch time.
- Interactive charts using Chart.js.

### 🎨 8. Modern User Interface
- Dark and light theme support.
- Responsive design for desktop and mobile.
- Sidebar navigation.
- Bento-style dashboard cards.
- Custom modals and toast notifications.
- Smooth transitions and interactive elements.

### 💾 9. Data Management
- Automatic LocalStorage saving.
- JSON data export.
- JSON import and restore.
- Copy data to clipboard.
- Offline functionality without a backend.

## 🚀 Getting Started

Follow these steps to run CineTrack locally.

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in VS Code.

4. Start organizing your entertainment library!
